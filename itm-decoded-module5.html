Section 1: Third-Party Integration

The Integration Landscape

First Due offers API integrations with LIV, IROL, and Brycer (TCE). This is a one-way PUSH from those platforms into First Due pre-plans. It provides operational awareness but does NOT include full ITM capabilities.

LIV

IROL

Brycer (TCE)

↓ ONE-WAY PUSH ↓
First Due Pre-Plans

Operations Awareness Only

⚠️ Critical Distinction

This API integration is LIMITED. It pushes system status to pre-plans but does NOT provide Fire Prevention integration, occupancy record linking, automated enforcement, or compliance workflows.

Section 1: Third-Party Integration

What the Integration Delivers

✓ What the API DOES Provide

  • System status pushed to Pre-Plan tiles
  • Red Tag/Out of Service flagging
  • Data in Life Safety System section
  • Firefighter operational awareness

✗ What the API Does NOT Provide

  • Full occupancy record integration
  • Automated enforcement workflows
  • Compliance check scheduling
  • Fire Prevention module integration
  • Property owner notifications
  • Report approval/rejection workflows
  • Deficiency tracking
  • Payment processing

⚠️ Bottom Line

The API gives Operations visibility into impairments. It does NOT give Fire Prevention the tools to manage ITM compliance. For that, they need native First Due ITM.

Section 2: Data Flow

The Data Flow

How data flows from third-party platforms—and where it stops:

1
Service Provider Submits

Contractor uploads report to LIV, IROL, or Brycer

2
Platform Processes

Platform manages compliance in THEIR system

3
ONE-WAY PUSH

Limited data: address, system type, status. No full report details.

4
Life Safety System Updated

Status populates Life Safety System in Occupancy; Red Tags flagged

🛑 Where It STOPS

The API push does NOT trigger: compliance check scheduling, property owner notifications, Fire Prevention workflows, deficiency tracking, or inspection integration.

All Fire Prevention management stays in the third-party platform.

  • NFPA 14 - Standpipes
  • NFPA 96 - Hoods
  • NFPA 10 - Extinguishers

  • State-specific requirements
  • Local amendments
  • AHJ policies

⚙️ How It Works

1) AHJ specifies adopted code editions → 2) Local amendments configured → 3) Every submission analyzed against that ruleset
