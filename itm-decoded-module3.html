Section 3: AHJ Dashboard

Understanding System Statuses

Every fire protection system in an ITM report has one of four statuses. Understanding these is crucial for demos:

Status Meaning Typical Action
Compliant System passed all tests, fully operational Approve report, no follow-up needed
Non-Critical Deficiency Minor issue found, system still functional Approve with noted deficiency, schedule follow-up
Critical Deficiency Significant issue affecting system performance Auto-schedule compliance check, notify property owner
Impairment System is out of service Immediate notification to operations, fire watch may be required

💬 Talk Track

"Each status can trigger different automated workflows. A compliant system might just get approved, but a critical deficiency automatically schedules a compliance check inspection and notifies the right people. You define the rules."

Section 6: Automated Enforcement

Automated Enforcement & Notifications

One of First Due's most powerful differentiators is the ability to automate enforcement actions based on ITM report statuses:

🎯 The Big Picture

When a service provider submits an ITM report, the system doesn't just store it—it monitors the status and automatically triggers the right actions based on rules you define.

Trigger: Initial System Status

When reports come in, actions are triggered based on these four statuses:

  • Compliant
  • Non-Critical Deficiency
  • Critical Deficiency
  • Impairment

Possible Actions

  • Flag report as Pending
  • Send email notifications
  • Schedule compliance check inspection
  • Generate compliance letters
  • Notify operations of impairments
Section 6: Automated Enforcement

ITM Setup: Initial Notifications

AHJs configure automated workflows in the ITM Setup section:

System Status Example Configuration
Compliant Auto-approve report, update occupancy record, no follow-up needed
Non-Critical Deficiency Flag for review, notify inspector, track for follow-up within 30 days
Critical Deficiency Flag Pending, notify Fire Marshal, schedule Compliance Check in 5 days
Impairment Immediate notification to Operations, update pre-plan, alert dispatchers

💬 Talk Track

"You define the rules once, and the system enforces them consistently. A critical deficiency on a sprinkler system at 2 AM gets the same follow-up as one submitted at 2 PM. No reports falling through the cracks."
